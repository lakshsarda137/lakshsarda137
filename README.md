# Laksh Sarda

I build small tools for things I got tired of doing by hand: copying tables out of PDFs,
checking five dining hall menus every morning, grading the same exam question multiple times.

### [Othello from self-play](https://github.com/lakshsarda137/rl-for-games/tree/main/othello)

A program that taught itself Othello with no human games. It beats me now, and you can
[play it](https://othello.lakshsarda.com).

### [Carbon](https://github.com/lakshsarda137/Carbon)

A macOS app that keeps tables, columns and bold text intact when you copy out of a PDF into
Google Docs, Word or Excel.
